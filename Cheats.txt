The problem is that sysPatch() calls location.reload(), which wipes everything you defined in the console. So after the first command, the helpers are gone.

Two fixes:

Fix 1: Re-paste the helpers after every reload
Paste this block every time the page reloads:

JavaScript

window.sysGet = () => JSON.parse(localStorage.getItem("sl_fitness_v3") || "{}");
window.sysSave = (d) => localStorage.setItem("sl_fitness_v3", JSON.stringify(d));
window.sysPatch = (p) => { sysSave({ ...sysGet(), ...p }); location.reload(); };
window.sysShow = () => console.table(sysGet());
window.sysReset = () => { localStorage.removeItem("sl_fitness_v3"); location.reload(); };
console.log("✓ Helpers loaded");
Fix 2: Use these standalone one-liners instead
